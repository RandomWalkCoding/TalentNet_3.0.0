# 本地 Demo 操作顺序

1. 运行根目录 `start.ps1` 或 `start.sh`，打开 `http://127.0.0.1:3025`。工作台从 `林晨`、`Maya Singh`、`周宇` 三条示例资料开始。
2. 在「公司」新增公司并编辑其行业或监控状态；在「候选人」创建、编辑资料，也可导入 CSV。CSV 至少包含 `name,company_name,title`。
3. 打开林晨详情：查看风险和证据，手工添加证据或上传 TXT/PDF/DOCX 等文本可提取文件；下载刚上传的原文件。刷新评分，生成摘要和联系话术。
4. 点击「公开网页核查」检查最新公开页面。打开来源核对草稿，只有待确认状态才能保存。浏览器或站点不可用时显示降级草稿，可手动编辑或改用证据表单；不会把失败的抓取宣称为已验证事实。
5. 将林晨加入猎场，登记 `contacted`，随后登记 `interested` 等后续结果。在「效能分析」查看触达率和反馈覆盖率变化；复制一条 AI 话术后，查看复制率。复制不代表实际发送。
6. 在「公司」再建一名归属 OpenAI、部门为 `Post-training Platform` 的候选人。打开「组织关系」，生成同部门疑似关系，查看双方资料后确认或否定。该线索不是汇报或合作关系的证明。
7. 顶部切换到「招聘顾问」或「观察员」，查看猎场数据归属；「经理视图」与操作审计仅经理可访问。返回「经理」查看席位活动、模型记录。

演示仅使用本机 SQLite。真实站点登录、模型服务及网页可达性由使用者自己的环境决定；没有集成自动发信、批量爬取或生产身份认证。
