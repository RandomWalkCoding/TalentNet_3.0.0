## 仍需外部条件或生产工程

| 项目 | 当前行为 / 原因 |
| --- | --- |
| 真实网页登录与全量平台数据 | 取决于站点可达性、账号授权和访问规则；本地能运行网页核查和人工确认，但不保证站点返回可识别的个人页面。没有批量爬取或绕过登录。 |
| 第三方模型 | 可配置兼容 API；无可用模型时走本地生成。真实调用取决于用户配置及服务可用性。 |
| 网络部署认证 | 本地身份切换仅用于 Demo；部署给多用户前需正式登录、会话管理、隔离和授权审计。 |
| 高级关系推断 | 当前只有同部门弱线索和人工决定；共同项目、上下级、论文作者等关系需要可信的成对证据与专门解析，不能从个人资料臆断。 |
| 扫描件 OCR / 任意附件 | 支持可提取文本的常见文件；图片型 PDF 和扫描件需 OCR 服务。 |
| 自动触达 | 目前只生成和复制话术，触达结果由用户登记；没有发送邮件或社交平台消息。 |

以上边界也适用于演示种子资料：其中人物和示例链接是演示数据，不能当作实时公开事实。
